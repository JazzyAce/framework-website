# FRAMEWORK

One-page landing site for **FRAMEWORK**, a proposed all-in-one film pre-production platform created by **Landon Clarken**.

This site describes the concept and its planned features; it is not yet a functioning production management app.

## Preview locally

Open `index.html` in a browser, or from Terminal inside the project directory run:

```bash
open index.html
```

## Deploy

Push `index.html`, `styles.css`, and `script.js` to a public GitHub repository, then import the repository in Vercel. Choose **Other** for the framework preset (a plain static site), leave the build command empty, and deploy.
